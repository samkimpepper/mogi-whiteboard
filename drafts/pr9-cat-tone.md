# PR #9 Whiteboard — 고양이 말투 수정 지침 😸🐾

사용자가 현재 Whiteboard 문서에도 `~라옹`, `~냐옹` 같은 고양이 말투와 고양이 이모지를 요청했다. 아직 이 세션에서 Whiteboard에 적용하지 못했다. MCP 읽기 호출이 승인 필요로 거절됐고 approval policy가 never다.

## 적용 대상

리뷰 ID: `f0081637-7560-480a-91df-275735cde566`

현재 리뷰를 다시 읽고 새 document lease를 얻어 수정한다. 사용자는 코드 조각 수정이 다른 세션에서 반영됐다고 알렸으므로 마지막으로 읽은 version 32를 통째로 덮어쓰지 않는다.

## 말투

- 설명 문장에 `~한다옹`, `~라옹`, `~냐옹`, `~해보자옹`을 자연스럽게 쓴다.
- 제목과 설명에 😸 🐾 🐈 😼 같은 고양이 이모지를 넣는다.
- 명령어·함수명·코드·경로·원문 링크·수치와 사실의 확실성은 그대로 보존한다.
- 작성자가 인용한 당시 대화 원문은 그대로 둔다. 당시 기록과 현재 회고의 구분도 유지한다.
- 최근 적용된 짧은 코드 블록을 유지한다. 코드 문자열에는 말투나 이모지를 넣지 않는다.
- 설명의 의미를 유지하면서 문단별로 수정하고, 전체를 다시 읽은 뒤 lease를 종료한다.

## 제목 수정 예시

- `무엇이 달라졌나 — 매일 아침 루틴을 macOS가 직접 실행 😸`
- `설계 — 설치는 한 번, 실행은 매일이라옹 🐾`
- `구현 — 필요한 코드 조각을 함께 읽어보자옹 🐈`
- `테스트 — 어떤 상황을 확인했냐옹? 😼`
- `운영 — 코드와 사람이 각각 확인할 일이라옹 🐾`

## 설명 수정 예시

휴일 루틴의 예약 담당이 Orca의 프롬프트 실행에서 macOS LaunchAgent로 바뀐다옹 😸 매일 09:00에 Node가 기존 `holiday-routine.js --apply`를 직접 실행하고, 오늘 루틴을 할지는 기존 코드가 판단한다옹.

`ProgramArguments`는 macOS에 넘길 실행 목록이라옹 🐾 `nodePath`는 Node의 절대 경로, `scriptPath`는 기존 루틴 파일 경로라옹. `--apply`는 조건이 맞을 때 실제 Things 반영을 허용하는 인자다옹.

매일 실행한다고 매일 Things에 할 일을 만드는 건 아니라옹 😼 그날이 휴일인지, 점심 시간에 약속이 있는지는 기존 루틴이 확인한다옹.

평일에 건너뛴 결과만으로 휴일의 Calendar·Things 권한과 실제 반영까지 확인한 건 아니라옹 🐈 첫 실제 주말·공휴일에는 권한과 Today 반영을 확인해야 한다옹.

위 문장은 말투 예시다. 실제 반영할 때는 현재 문서의 원문 링크와 설명 내용을 유지한다.
